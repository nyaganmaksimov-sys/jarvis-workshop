# Архитектура Jarvis Workshop v1

## Компоненты

### 1. Camera Layer
Источники видео: RTSP/ONVIF IP-камеры и USB-камеры. Для каждого источника задаются идентификатор, зона наблюдения, связанное оборудование и частота анализа.

### 2. Edge Agent
Локальный процесс в цехе. Получает кадры, нормализует их, запускает детекторы и отправляет на сервер только состояние и нужные кадры событий.

### 3. Vision Pipeline
В v1 допускается сочетание простых правил, компьютерного зрения и мультимодального анализа. Полный видеопоток не обязан уходить в облако.

### 4. State Engine
Сводит отдельные наблюдения в устойчивое состояние устройства. Состояние не меняется от одного случайного кадра: используется временное подтверждение и confidence.

### 5. Event Bus
Формирует события изменения состояния и аномалий.

### 6. Jarvis API
Отдаёт список устройств, камер, текущее состояние, журнал событий и снимки. Принимает heartbeat от Edge Agent.

### 7. A4Print-HUB Adapter
Отдельный адаптер связывает `device_id` и `production_job_id` / `order_id`. HUB не должен напрямую работать с RTSP или внутренностями камер.

## Поток данных

```text
Camera -> Edge Agent -> Observation -> State Engine -> Event -> Jarvis API -> HUB
```

## Правило безопасности

Команды управления оборудованием проектируются отдельным контуром с allow-list, аудитом и подтверждением пользователя. В v1 actuator layer отсутствует.
