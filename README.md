# Jarvis Workshop

Система визуального контроля цеха для А4-Принт / 3D-ARTPRINT.

## Цель

Jarvis Workshop наблюдает за оборудованием через камеры и локальные интеграции, определяет состояние станков, фиксирует события и передаёт их в A4Print-HUB.

## Принципы v1

- локальная обработка видеопотока в цехе;
- камеры RTSP/ONVIF;
- отдельный Edge Agent рядом с оборудованием;
- сервер событий и API;
- безопасный режим: v1 наблюдает и уведомляет, но не управляет станками автоматически;
- возможность последующего подключения оборудования через API/локальную сеть;
- интеграция с A4Print-HUB только через API.

## Архитектура

```text
IP-камера / USB-камера
        │
        ▼
   Edge Agent
 camera → vision → detectors
        │
        ▼
  Jarvis Workshop API
        │
        ├── события / тревоги
        ├── состояние оборудования
        └── снимки событий
        │
        ▼
    A4Print-HUB
```

## Структура

```text
edge-agent/   локальный агент в цехе
server/       API и модель событий
dashboard/    будущая панель «Джарвис · Цех»
config/       камеры и оборудование
docs/         архитектура, железо и интеграции
deploy/       Docker и развёртывание
```

## Первый пилот

Первым оборудованием планируется FlashForge AD5X. Первая камера должна видеть рабочую область принтера и, при необходимости, дисплей.

Минимальные состояния v1:

- OFFLINE
- IDLE
- PRINTING
- PAUSED
- DONE
- ERROR
- UNKNOWN

Первый набор событий:

- device.online
- device.offline
- job.started
- job.progress
- job.completed
- job.paused
- anomaly.detected
- camera.offline

## Безопасность

До отдельного этапа управления Jarvis Workshop не должен автоматически запускать, останавливать или физически переключать оборудование. Сначала система работает как наблюдатель и диспетчер.
