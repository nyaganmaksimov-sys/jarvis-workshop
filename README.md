# Jarvis Workshop

Локальная система визуального и голосового контроля цеха для А4-Принт / 3D-ARTPRINT.

## Цель

Jarvis Workshop наблюдает за оборудованием через камеры и локальные интеграции, определяет состояние станков, фиксирует события, отвечает на голосовые/текстовые запросы и передаёт данные в A4Print-HUB через API.

## Принципы v1

- локальная обработка видеопотока в цехе;
- камеры RTSP/ONVIF;
- отдельный Edge Agent рядом с оборудованием;
- сервер событий и API;
- локальный голосовой интерфейс с wake-word «Джарвис»;
- локальная LLM через Ollama с безопасным fallback без LLM;
- собственная локальная память на SQLite;
- безопасный режим: v1 наблюдает и уведомляет, но не управляет станками автоматически;
- возможность последующего подключения оборудования через API/локальную сеть;
- интеграция с A4Print-HUB только через API.

## Core v0.2

`core/brain.py` — local-first reasoning. Типовые команды цеха обрабатываются без LLM, сложные запросы могут уходить в локальный Ollama.

`core/memory.py` — локальная долговременная история диалогов на SQLite.

`core/voice.py` — офлайн-распознавание речи через Vosk и wake-word «Джарвис». Голосовые зависимости вынесены отдельно в `core/voice-requirements.txt`.

`core/orchestrator.py` — связывает запрос пользователя, память и актуальный снимок состояния цеха.

## API ассистента

```http
POST /api/v1/assistant/query
Authorization: Bearer <JARVIS_API_KEY>
Content-Type: application/json

{"text":"Джарвис, как дела в цехе?"}
```

Ассистент получает текущие `devices` и последние `alerts` перед формированием ответа, поэтому не должен выдумывать состояние оборудования.

## Первый пилот

Первым оборудованием планируется FlashForge AD5X. Первая камера должна видеть рабочую область принтера и, при необходимости, дисплей.

Минимальные состояния v1:

- OFFLINE
- IDLE
- PRINTING
- PAUSED
- DONE
- ERROR
- UNKNOWN

Первый набор событий:

- device.online
- device.offline
- job.started
- job.progress
- job.completed
- job.paused
- anomaly.detected
- camera.offline

## Безопасность

До отдельного этапа управления Jarvis Workshop не должен автоматически запускать, останавливать или физически переключать оборудование. Сначала система работает как наблюдатель и диспетчер.

Проект `riwvv/Jarvis` используется только как функциональный референс. Его proprietary-код не копируется в этот репозиторий.
